# Versioned wire format

`v0.1.0.schema.json` describes the original required JSON fields and types. `v0.2.0.schema.json` adds an owner-only `source_recorded` event with a canonical JSON string. Both are generated by `python3 schema/write_schema.py` and checked against synthetic cases by `tests/test_schema.py`. The Lean `replay` function is normative for identity, reference, causal time, exact numeric, cost, verdict, decision, and source-trace relationship rules. Schema and semantics versions must be a supported matched pair; migration is explicit and not implemented in V0.

All exact measurements and thresholds are decimal strings. `null` means no measurement; it is not zero. Unknown JSON fields fail in owner validation. Agent projection strips hidden objects before validation or derived views, so hidden extension data cannot enter the agent export. Export order and encoding are deterministic for the pinned toolchain. The source JSON string retains parsed fields and values, not original whitespace or byte formatting; the original files remain the byte-level authority.
