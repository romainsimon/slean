# Versioned wire format

`v0.1.0.schema.json` describes the original required JSON fields and types. `v0.2.0.schema.json` adds an owner-only `source_recorded` event with a canonical JSON string. `v0.3.0.schema.json` adds `dependency_gate_recorded`: an explicit `all_of` or `any_of` group with at least two distinct prior member IDs, one prior target ID, and a recorded `support` or `prerequisite` kind. The gate describes an author's dependency claim; Slean does not evaluate whether its members are true or sufficient. All three schemas are generated by `python3 schema/write_schema.py` and checked against synthetic cases by `tests/test_schema.py`. The Lean `replay` function is normative for identity, reference, causal time, exact numeric, cost, verdict, decision, and source-trace relationship rules. Schema and semantics versions must be a supported matched pair; migration is explicit and not implemented in V0.

All exact measurements and thresholds are decimal strings. `null` means no measurement; it is not zero. Unknown JSON fields fail in owner validation. Agent projection strips hidden objects before validation or derived views, so hidden extension data cannot enter the agent export. Export order and encoding are deterministic for the pinned toolchain. The source JSON string retains parsed fields and values, not original whitespace or byte formatting; the original files remain the byte-level authority.

The frozen protocol's `cost_cap` applies to the sum of recorded amounts in `cost_unit` across all runs that reference that protocol. The earlier untagged candidate checked each run separately. This pre-publication correction can reject a multi-run case that the earlier candidate accepted; the 0.1–0.3 wire shapes are unchanged. A later change to the published meaning of a version needs a new semantics version.

`export-v0.1.0.schema.json` describes the separate CLI export envelope: `format`, `lean_version`, and a `case` that still follows its own 0.1, 0.2, or 0.3 schema. The Lean version identifies the exporter; it is not a claim that imported data or a proof was independently verified. The `export-case` command preserves the original raw-case output for fixture consumers. An incompatible envelope version is rejected; Slean does not migrate it implicitly.

[`examples/dependency-gates.json`](../examples/dependency-gates.json) is the synthetic 0.3 example. Its AND gate records that both a frozen protocol and an assessment are prerequisites of the decision; its OR gate records two alternative observation references for the claim. Neither gate changes the exact one-observation assessment or promotion rule. A gate referencing a later or hidden object cannot create a visible agent gate: replay rejects a later reference, and projection removes a gate whose members are not all visible.
