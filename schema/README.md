# Versioned wire format

`v0.1.0.schema.json` describes required JSON fields and types. It is generated by `python3 schema/write_schema.py` and checked against the public fixtures by `tests/test_schema.py`. The Lean `replay` function is normative for identity, reference, causal time, exact numeric, cost, verdict, and decision rules. A different `schema_version` or `semantics_version` fails; migration is explicit and not implemented in V0.

All exact measurements and thresholds are decimal strings. `null` means no measurement; it is not zero. Unknown JSON fields fail in owner validation. Agent projection strips hidden objects before validation or derived views, so hidden extension data cannot enter the agent export. Export order and encoding are deterministic for the pinned toolchain.
