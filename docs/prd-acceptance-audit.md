# Slean PRD acceptance audit — 2026-09-23

The approved CEO program PRD v1.1 (2026-09-23) defines the criteria below. CEO maintains that decision document outside Slean. It does not grant a public licence, merge, release tag, repository visibility change, site deployment, or scientific result.

An open PR is never counted as a released capability.
