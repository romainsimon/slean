# Slean PRD acceptance audit — 2026-09-23

The approved CEO program PRD v1.1 (2026-09-23) defines the criteria below. CEO maintains that decision document outside Slean. This audit distinguishes evidence on `main` at `72a916f` from candidates in open pull requests. It does not grant a public licence, merge, release tag, repository visibility change, site deployment, or scientific result.

**Evidence states:** `local` means observed against a named source revision; `candidate` means an open PR has local evidence but is not merged; `partial` means a named part of the criterion is absent; `external` means another owner or a human study must act. An open PR is never counted as a released capability. [Dependency gate PR #4](https://github.com/romainsimon/slean/pull/4) at `5d0c98d` is stacked on [Explorer PR #3](https://github.com/romainsimon/slean/pull/3), not on `main`.

[Plausible PR #2](https://github.com/romainsimon/slean/pull/2) is a separate analytics change. It supplies no DOC or VIS acceptance evidence in this audit.
The final sentence of `ROADMAP.md` on `main` still says no remote `main` commit exists. That statement is stale; [Explorer PR #3](https://github.com/romainsimon/slean/pull/3) corrects it, pending merge.

## Three unresolved gates

1. **DOC-01 at a tag.** The [local annotated-tag rehearsal](local-tag-build.md) proves the candidate docs commit builds from a clean checkout selected by a tag kept only in a temporary clone. After publication approval, repeat the check from the exact public release tag, compile every shown example, inspect `build-info.json`, and compare the public site's displayed tag and route to that same revision. Until then DOC-01 remains partial; inventing a “development tag” in the UI would misstate release state.
2. **VIS-01 ET/OU.** A list of binary edges cannot distinguish “all prerequisites” from “any one alternative.” PR #4 supplies a versioned, audience-filtered gate object with explicit member IDs and operator, prior-reference and chronology checks, and matching accessible list/2D rendering for a synthetic case. It has not been merged or checked against an accepted representative dossier. The reserved Lean `DependencyExpr` is still not a general evaluation engine. Do not infer ET/OU from graph topology or treat grouped support as a scientific verdict.
3. **SL-009 3D.** The Blueprint and Explorer prototypes do not measure a Z-axis benefit. Use the [task protocol](3d-task-study-protocol.md); if a representative ET/OU dossier or target reviewers are unavailable, record “not run” and preserve the 2D/table view. A local screenshot is not a task result.
